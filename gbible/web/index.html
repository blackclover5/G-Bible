Devotional creator Turn your library into a daily devotion.

How it works
Pick any Bible or chaptered book from your library, choose how much of it you want, and the days it should fill. G-Bible builds a numbered reading plan and opens each day in the original resource pane, with temporary day markers while the plan is active.
Bibles are split by chapter — never mid-chapter. Anything else is split at sentence boundaries — never mid-sentence. Days are portioned as evenly as the text allows, by word count.
The devotion's text is copied from the installed module, so it carries that module's licence and attribution. Created devotions repeat yearly on the same month-and-day, like a printed daily devotional. If this tool made it, it can be deleted from the list below.
